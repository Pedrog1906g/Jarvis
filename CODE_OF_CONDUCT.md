# Código de Conduta

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/), versão 2.1.

## Nossa promessa
Nós, como membros, contribuidores e mantenedores, prometemos fazer de nossa participação uma
experiência livre de assédio para todos, independentemente de idade, corpo, deficiência, etnia,
identidade de gênero, nível de experiência, nacionalidade, aparência, religião ou orientação sexual.

## Comportamento esperado
- Demonstrar empatia e respeito.
- Aceitar críticas construtivas com elegância.
- Focar no que é melhor para a comunidade.

## Comportamento inaceitável
- Linguagem ou imagens sexualizadas, bem como assédio de qualquer tipo.
- Trolling, insultos, comentários depreciativos ou ataques pessoais.
- Divulgação de informações privadas de terceiros sem permissão.

## Aplicação
Casos de comportamento abusivo podem ser reportados ao mantenedor do projeto. Decisões seguem
as diretrizes do Contributor Covenant.
