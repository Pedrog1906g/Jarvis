# Contribuindo com o NEXUS AI

Obrigado por querer contribuir! 🧠

## Como contribuir

1. Faça um **fork** do repositório.
2. Crie uma branch a partir de `main`: `git checkout -b feat/minha-melhoria`.
3. Mantenha os **commits pequenos e bem descritos** (ex.: `feat:`, `fix:`, `docs:`, `refactor:`, `build:`).
4. Garanta que **nada pare de funcionar** (rode os testes: `cd backend && pytest`).
5. Abra um **Pull Request** descrevendo a mudança.

## Padrões de código

- **Python:** PEP 8, type hints quando possível, comentários em português ou inglês claro.
- **JavaScript/HTML:** sem frameworks no HUD/demo (HTML/CSS/JS puro).
- **Kotlin (Android):** padrões do projeto, recursos em `strings.xml`.
- Nomes descritivos; evite código morto e imports não utilizados.

## Segurança

- **Nunca** envie segredos (tokens, chaves, `.env`) para o repositório.
- Use variáveis de ambiente / painel do Render.
- Vulnerabilidades: abra relatório privado (veja `SECURITY.md`).

## Identidade visual

- O símbolo oficial (cérebro cibernético em falha) está em `assets/`.
- Mantenha a paleta: preto, azul neon, vermelho neon (somente alertas) e branco.
- Créditos: `Designed & Developed by Pedrog1906g`.
